# 电热合金米电阻 & 元件设计计算 Agent (Electro-Alloy Calc)

铁铬铝（Fe-Cr-Al）与镍铬（Ni-Cr）合金的米电阻与电热元件设计计算工具。

## 💡 功能

- **米电阻正/反向**：圆丝、扁带/扁丝的米电阻中值与上下限，按目标阻值反推丝径/厚度。
- **质量/电阻核算**：已知尺寸+长度 → 截面积、体积、质量、常温电阻。
- **电阻反算长度**：已知目标电阻与尺寸 → 所需长度与质量。
- **电参数核算**：给定功率+电压（或功率+电阻）→ 电阻、长度、质量、常温/高温表面负荷。
- **螺旋丝核算/设计**：已知几何 → 展开长度/质量/电阻/功率/表面负荷；或给定设计功率/电压/目标表面负荷 → 理论丝径、圈数、螺旋尺寸。
- **波浪元件核算/设计**：圆丝或扁带的波浪元件，已知几何 → 全部电参数；或逆推理论规格与波数。
- **牌号自动识别**：255、1560、2080、21al6nb、HRE、HYZ 等；内置电阻率、密度、电阻温度系数工程库。

## 🚀 使用说明（WorkBuddy / Agent）

1. 克隆本项目：

   ```bash
   git clone https://github.com/fjf1113/electro-alloy-calc.git  
   ```

2. 在 WorkBuddy 或 Agent 平台的对话框内输入上面的指令让其进行安装。

3. 在微信（设置里绑定）/对话框中即可自然语言提问（如："算一下 255 宽 3.5 厚 0.3 扁带米阻"）。


## ⚠️ 工程边界

计算为理论参考值；`temp_factor`、最高使用温度、推荐表面负荷为参考值，关键选型以牌号标准与研发复核为准。
